# The Restaurant Website

A small responsive restaurant website built with HTML and CSS for Month 1 practice.

## Files
- `index.html` — semantic page structure and sample menu content
- `style.css` — lilac, plum and butter-yellow palette, responsive layout, and CSS burger illustration

## Run it
Open `index.html` in your browser. No installation is required.

## Learning checklist
1. HTML structure: `header`, `nav`, `main`, `section`, `article`, `footer`
2. Navigation links and section IDs
3. CSS variables, typography, spacing, flexbox, and grid
4. Hover effects and responsive media queries

Menu items, prices, address, and phone number are sample placeholders. Replace them with real details before publishing.
